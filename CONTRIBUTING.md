# Contributing to lunaPortal

Thanks for helping build the mirror index.

## Submitting a project

1. Fork the repository.
2. Copy `TEMPLATES/request.html` to `requests/<your-github-username>.html`.
3. Fill in the placeholders — do not change the structure or remove sections.
4. Commit, push, and open a Pull Request.
5. Wait for review. A maintainer may ask you to fix links or metadata.

## Guidelines

- **Open source only.** OSI-approved licenses.
- **Working links.** Verify each mirror before submitting.
- **One file per project.** `requests/<username>.html`.
- **No structural edits to the template** in a request PR — those belong in a
  separate PR against `TEMPLATES/request.html`.
- **Keep it clean.** No tracking parameters, no URL shorteners.

## Reporting dead mirrors

Open an issue with the portal URL and the broken link.
