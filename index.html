Workflow

How lunaPortal Works

You submit your mirrors once via Pull Request. We review the request, verify link availability, and publish your personal portal hub.

01

Download Template

Grab TEMPLATES/request.html from the repository.

Single-file HTML
02

Fill Mirror Links

Set ProjectName and replace "None" with your active URLs.

Auto-hides "None"
03

Open Pull Request

Save as requests/<username>.html and open a PR against main.

GitHub PR flow
04

Review & Check

We verify OSI-approved open-source licensing and public mirror reachability.

Community curated
05

Your Portal Link

Once merged, your hub goes live at portal.lunaoss.tech/cloud/<user>.

Always in sync
Quickstart

Submit Your Project

Fork the repository, copy TEMPLATES/request.html to requests/<your-username>.html, fill in your variables, and open a Pull Request.

bash — submit-portal.sh 
# 1. Fork the repository on GitHub, then clone:
git clone https://github.com/<your-username>/Portal.git
cd Portal

# 2. Create a request branch
git checkout -b request/<your-username>

# 3. Copy the template and fill in your mirrors
cp TEMPLATES/request.html requests/<your-username>.html
$EDITOR requests/<your-username>.html

# 4. Commit and push
git add requests/<your-username>.html
git commit -m "request: add <project-name>"
git push origin request/<your-username>
Zero-Database Config

Inside the HTML Template

No build tools or external databases required. Open TEMPLATES/request.html and edit the JavaScript constants at the top of the file:

TEMPLATES/request.html (Configuration Block) "None" = Auto-Hidden 
// Project Metadata
const ProjectName = "Portal";
const Description = "Short description of your open-source release.";
const Version     = "v1.0.0";
const ReleaseDate = "None";
const FileSize    = "None";
const Maintainer  = "magic4n";

// Optional Integrity Checksums
const MD5_Checksum    = "None";
const SHA256_Checksum = "None";

// Mirror Links (SourceForge, Yandex, Google Drive 1-5, GitHub, Telegram, etc.)
const SourceForge   = "https://sourceforge.net/projects/...";
const YandexDrive   = "None";
const GoogleDrive_1 = "https://drive.google.com/...";
const GoogleDrive_2 = "None"; // Up to GoogleDrive_5
const GitHub        = "https://github.com/magic4n/Portal";
const Telegram      = "https://t.me/...";
const Mega          = "None";
const MediaFire     = "None";
const OneDrive      = "None";
const DirectLink    = "None";
Index Policy

Submission Requirements

✓

Open Source Only

The project must be publicly available under an OSI-approved license.

✓

Publicly Reachable

Every submitted mirror link must load cleanly without requiring a login wall.

✓

Your Own Project

You are the maintainer, or you have explicit permission to submit the project.

✓

One Request Per Project

All mirrors (up to 13 built-in slots) go inside the same single request HTML file.

✓

Safe & Clean Content

Strictly no malware, scams, NSFW, or illegal files permitted in the index.

✓

Working Mirrors

Mirrors are periodically re-checked; dead links are pruned to keep the hub reliable.
